## Flow Launcher Tags
A simple [Flow Launcher](https://github.com/Flow-Launcher/Flow.Launcher) plugin that allows tagging installed programs.

## Current capabilities
- indexing installed programs in Windows registry
- basic commands to assign, remove tags and list programs

## Installation
Download the latest release, unzip it and put the folder here: <br>
`%AppData%\FlowLauncher\Plugins\`

## Usage
Default activation keyword: `tag`.

- List programs by tag: <br>
`<keyword> <tag_name>`

- Add tag to a program: <br>
`<keyword> add <tag_name> <program_name>`

- Remove tag from a program: <br>
`<keyword> remove <tag_name> <program_name>`
